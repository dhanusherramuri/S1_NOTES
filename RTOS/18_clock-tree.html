STM32F103 Clock Tree - Reference

Every clock signal on the chip traces back to one of four sources, through at most one multiplier and a couple of dividers. This is the whole tree in one diagram, followed by the handful of configurations actually worth knowing.

Why this bites people. Set the wait states after switching to 72 MHz and the very next instruction fetch can already be too fast for flash to keep up - the fix is always latency first, frequency second, exactly the order used in clock_setup_hse_pll_72mhz() in this workspace's three-thread-blink_hse project.

Configuration options that actually get used

Of all the combinations the tree above allows, a handful cover nearly every real project.

ConfigurationSYSCLKAHB/APB1/APB2Flash WSWhen to use it
HSI direct
no PLL, no crystal		 8 MHz 8 / 8 / 8 MHz 0 Default at reset. Fine for bring-up, or anything not timing-sensitive. What every project in this workspace uses except one.
HSE direct
no PLL, crystal fitted		 = crystal freq (e.g. 8 MHz) matches SYSCLK 0 (at 8 MHz) Same speed as HSI but ±1% accuracy instead of HSI's looser tolerance - useful when timing correctness matters more than raw speed.
HSI + PLL
no crystal needed		 up to 64 MHz e.g. 64 / 32 / 64 MHz 2 Full speed on boards with no HSE crystal fitted at all. Input is fixed at HSI/2 = 4 MHz, so the multiplier alone sets the ceiling (x16 → 64 MHz).
HSE + PLL
the common "full speed" setup		 72 MHz 72 / 36 / 72 MHz 2 Maximum rated speed, HSE accuracy. 8 MHz × 9 = 72 MHz - exactly clock_setup_hse_pll_72mhz() in three-thread-blink_hse.
HSE + PLL, USB-capable 72 MHz 72 / 36 / 72 MHz 2 Same as above, plus USBPRE set to /1.5 so PLLCLK (72 MHz) divides down to exactly 48 MHz for the USB peripheral.

Why 72 MHz specifically. It's not an arbitrary round number - it's the documented maximum SYSCLK for the whole F103 line, and 8 MHz × 9 is the multiplier that lands exactly on it using the crystal nearly every board (including the Bluepill) actually ships with. Boards with a different crystal need a different PLLMUL to reach the same ceiling - the target frequency is fixed by the silicon, the multiplier is the variable.
